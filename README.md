# FitPulse website

This is the standalone FitPulse landing/dashboard prototype. It uses sample activity data and does not connect to Health Connect, Supabase, or live GPS yet.

## Deploy on Vercel
1. Create a GitHub repository named `fitpulse`.
2. Upload `index.html` and this `README.md` to the repository root.
3. In Vercel, choose **Add New → Project**, import the `fitpulse` GitHub repository, and deploy with the default settings.
4. Vercel will provide a public `*.vercel.app` URL.

No build command or environment variables are required for this static prototype.
